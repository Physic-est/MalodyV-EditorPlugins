# ES3

Extra-Slide v3（Slide モードの Free Mode スキン）で使う拡張ファイル `lane3d.ex` を、
Composer の編集画面から作るためのプラグイン。

空中要素（AirTap / AirLift / AirSlide）を画面をなぞって置き、床のノーツから変換し、
小節線とカメラ演出を1行で足し、拍を ms に直して `lane3d.ex` へ書き出す。
**キーボードが無くても全部できる**。

## 入っているもの

| プラグイン | 種類 | 何をするか |
|---|---|---|
| **ES3 Draw** | ボタン | 置く。タップ = AirTap / ドラッグ = AirSlide |
| **ES3 Lift** | ボタン | AirLift（床 ⇄ 空中）。ドラッグ=長さあり / タップ=直角 |
| **ES3 Edit** | ボタン | 選ぶ・時刻や幅を掴んで変える・消す |
| **ES3 Convert** | メニュー | 選んだ床のノーツを空中要素に変換する（Tap→AirTap / Slide→AirSlide） |
| **ES3 Insert** | メニュー | `cam`（カメラ演出）と `measure`（小節線）を1行で足す |
| **ES3 Config** | メニュー | 幅・ease・横グリッドを1行で決める（`64,0,auto`） |
| **ES3 Undo** | メニュー | 1手戻す |
| **ES3 Export** | メニュー | `lane3d.ex` を書き出す。**最後に必ず実行する** |
| **ES3 Review** | AI Review | 規約チェック |
| **ES3 Check** | メニュー | この端末で API が使えるかの確認（最初に1回） |
| **ES3 Help** | ボタン | **使い方のパネルを出す**。タップかボタンで閉じる |

## 使い方

操作を忘れたら **ES3 Help** のボタンを押せば、編集エリアに早見表が出る。

1. Slide の譜面を開く。譜面の **Free Mode を ON** にしておく（スキン側の条件）
2. **ES3 Check** を1回実行して、`NG 0件` になることを確認する
3. **ES3 Draw** のボタンを押して、編集エリアをなぞって置く
   - **タップ** … AirTap
   - **ドラッグ** … AirSlide。縦に引けば x が変わらない帯（その場で押さえ続ける）、
     斜め・横に引けばその分だけ横へ動く帯になる。下へ引いても同じ帯になる
   - 他の要素の端の近くで始めると、その端に吸い付く（繋ぎ目スナップ）
4. 床と空中を行き来させたいところは **ES3 Lift**
   - **縦にドラッグ** … 長さのある AirLift。**上へ引けば `up`（床 → 空中）/ 下へ引けば `down`**。x は開始点に固定
   - **何も無いところをタップ** … **直角の AirLift**（長さ0）。その瞬間に床 ⇄ 空中を移る継ぎ目
   - **既にある Lift をタップ** … `up` と `down` を入れ替える
   - 直角は押さえ続ける時間が無いので、判定も配点も持たない（見た目だけ）
5. 既に書いた床のノーツを空中へ移したいときは、選んでから **ES3 Convert**
   - Tap / Wipe / フリック → AirTap、Slide → 折れ点ごとの AirSlide、Hold → その場の AirSlide
   - **元のノーツは消える**（Editor 本体の Undo で戻せる）。床にも残したいなら置き直す
   - 空中へ上がる AirLift は付かない。必要なら **ES3 Lift** で足す
6. 直すときは **ES3 Edit**。タップで選び、**選んである要素をもう一度タップで削除**
   - **細い芯の端をドラッグ** … 時刻を伸ばす／縮める
   - **頭・尻尾の幅の部分をドラッグ** … **幅を変える**（中心は動かさない。横グリッドの刻みに載る）
   - **芯の真ん中をドラッグ** … 全体を動かす
7. 終わったら **ES3 Export**。`lane3d.ex` ができる

**BPM やオフセットを変えたら、ES3 Export をもう一度実行する**だけで全部の時刻が付け直される。

## ファイル

| ファイル | 中身 |
|---|---|
| `lane3d.src` | プラグインが読み書きするソース。**時刻は拍**。これが正 |
| `lane3d.ex` | スキンが読む生成物。**時刻は ms**。Export で作られる |

`lane3d.src` はテキストなので直接書いてもよい。書式は `lane3d.ex` と同じで、
時刻だけが `8:48/96`（8拍目 + 48/96拍）の形になっている。

既に手で書いた `lane3d.ex` がある譜面では、`lane3d.src` が無ければそれを取り込む。

## スナップ

| | 何に合わせるか |
|---|---|
| **縦（拍）** | **エディターの分割設定そのまま**。1/4 にしていれば 1/4 刻みで置かれる |
| **横（x）** | 既定は**譜面に既にあるノーツから推定したグリッド**。4列の譜面なら 31 / 95 / 159 / 223 |

横だけ推定なのは、**エディターの横グリッドの倍率を読む API が無い**ため
（増減する `CallShortcut(39/40)` はあるが getter が無い）。
推定が合わないときは **ES3 Config** で固定できる。

- `auto` … 譜面のノーツから推定（既定）
- `0` … 横のスナップをしない（0〜255 のどこにでも置ける）
- `4` / `8` / `16` … その列数の中心に載せる

**ES3 Config** は `幅,ease,横グリッド` を1行で受け取る（例 `64,0,auto`）。
変えないところは空のままでよい（`96,,` なら幅だけ変わる）。

いま何が効いているかは、プラグインを開いたときのメッセージと `ShowTip` に出る
（`横グリッド 4分割の中心` のように）。

## ノーツごとのスクロール速度

床のノーツは**グループごと**に流れる速さを変えられる。

1. Composer の**ノーツグループ機能**で、速さを変えたいノーツに番号を付ける（0 が既定）
2. **ES3 Insert** で `hs,1,2` のような行を足す（グループ1 を2倍の速さに）

倍率は 0.1〜10、1 が既定で大きいほど速い。**判定の時刻は変わらない**（見える位置だけ）。
同じ時刻のノーツでも、グループが違えば違う速さで流せる。
空中要素はグループを持たないので常に既定の速さ。

## ease は曲線

`ease` は AirSlide / AirLift の**動きの付け方**。x が時間に対して非線形に動くので、
0 以外では実際に弧を描いて流れる。オーバーレイも ease どおりの折れ線で描いている。

| ease | x の動き | 見え方 |
|---|---|---|
| 0 | 等速 | 直線 |
| 1 | 遅く出て加速 | 始点側にふくらむ |
| 2 | 速く出て減速 | 終点側にふくらむ |
| 3 | 両端がゆるやか | S字 |

任意の曲線は引けない。**この4種から選ぶ**。既定値は **ES3 Config** で変える。

## 帯の見え方

帯は**芯を細く、頭と尻尾だけ幅を持たせて**描いてある。
幅を全長にわたって塗ると画面が埋まって読めなくなるので、幅は端だけで見せる。
掴み分け（時刻 / 幅 / 移動）もこの見た目に合わせてある。

斜めの帯は**回転させずに、区間を刻んだ軸沿いの帯**を並べている。
回転で引くには `HeightBeat` → `Height` の読み返しが要るが、これが当てにならず
実機でオーバーレイが扇状に崩れた（2026-09-20）。

## 色

| 見た目 | 中身 |
|---|---|
| 青 | AirTap / AirSlide |
| 紫 | AirLift（`up`） |
| 橙 | AirLift（`down`） |
| 白い端 | 空中判定線の側の端 |
| 黄 | 選択中 |
| 赤 | 規約違反（却下されるもの） |
| 左脇の緑の帯 | カメラ演出（`cam`）の区間 |

## キーボードの近道（PC のみ）

無くても全部できる。あれば速いというだけ。

| キー | |
|---|---|
| `1` `2` | AirTap / AirSlide に固定 / `0` で自動に戻す（Draw） |
| `Delete` | 選択中を削除（Edit） |
| `Z` | 1手戻す |
| `S` | 書き出し |

## 開発者向け

Malody のプラグインは Lua の `require` が使えないので、共通処理は各ファイルにコピーしてある。
正は `ES3-Draw.lua` の `-- >>> LANE3D COMMON` と `-- >>> LANE3D OVERLAY` ブロック。
直したら同期する:

```
python tools/sync-common.py          書き込む
python tools/sync-common.py --check  差分の有無だけ見る
```

配布する zip に `tools/` と `README.md` は要らない（`.lua` と `.png` だけ）。
